# Zahraa's project scrapbook

A personal portfolio of handmade cardboard buildings, crafts, and useful objects. Keep the real work central. This is a custom visual direction, not an implementation of a branded component library.

## Visual system

- Paper: blush #fff5f7. Ink: plum #493540. Secondary text: #775b69. Primary berry accent: #a43163. Lilac #f5eefb and butter yellow #fff7e8 are decorative paper tints.
- Fredoka 700 for the rounded reference-style headings, Nunito for body text, Patrick Hand for captions, and Caveat 400 for the handwritten wordmark. Fonts are locally hosted with their OFL licenses.
- Square photo mats, subtle paper texture, light tinted shadows, and occasional masking tape in the hero. No dashboard cards, gradients, promotional counters, or stock portfolio images.
- Layout variation 8/10, motion 3/10, visual density 3/10. Motion only acknowledges interaction; reduced-motion preferences are respected.
- Desktop: asymmetric photo collage and three unequal gallery columns. Tablet: two columns. Mobile: a single gallery column with readable captions.
- Light-only is deliberate: the page emulates a paper scrapbook.
- Keep existing anchors, project content, and chronological groupings. The new photos have a neutral 2026 heading because their academic year is unconfirmed.

## References and how they were used

- [Taste Skill](https://github.com/Leonxlnx/taste-skill): brief-first redesign audit, typography and spacing, avoidance of repeated generic components, reduced motion, and restrained animation.
- [Vercel Web Design Guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines): native controls, skip link, focus restoration, modal behavior, image dimensions, local font loading, filter state in URLs, and accessible mobile navigation. First-person copy is intentionally appropriate for this personal portfolio.
- [Awesome DESIGN.md](https://github.com/voltagent/awesome-design-md), especially its Miro analysis: a canvas-like arrangement of real artifacts, a consistent token system, and responsive control sizing. No Miro branding or proprietary fonts were copied.
- [Screenshot-to-Code](https://github.com/abi/screenshot-to-code): reviewed its image prompt and screenshot-preview loop; matched composition and typography while keeping original project photos. Its API-backed generator was not run because no model-provider key is configured.
- [Microsoft Playwright CLI](https://github.com/microsoft/playwright-cli): used the installed Playwright CLI browser session to inspect desktop/mobile rendering and test the functional flows.

## Visual references

Two design-only mockups were generated with the built-in image generator: a hero and a project gallery. They guided the bold typography, square photographic mats, spacing, and asymmetry. They are not embedded into the website, and invented details from mockups are not used as project evidence.

## Verification

45 projects; all 49 project photos load. Checked filtering, filter restoration after reload, keyboard opening, photo navigation, Escape, focus return, mobile menu, reduced motion, and absence of horizontal overflow at 320, 390, 768, 1024, and 1440 pixels. Desktop and mobile screenshots were visually inspected. Public deployment has not been performed.

## Palette revision
The user requested feminine, cutesy colors. The final palette uses blush paper, berry lettering, lilac photo mats, pink tape, and butter-yellow details. Layout and original photos remain intact.

## Reference fidelity correction
Matched the generated references more closely after user feedback: rounded heavyweight display letters, larger hero prints, -4.5-degree and +7-degree rotations, tighter photo crops, external handwritten captions and arrows, hand-drawn accent marks, and a gallery with two tall featured items beside two smaller ones. The actual project photographs and blush/lilac palette are retained. The original full photographs remain available in the viewer.
